# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through
[GitHub's security advisories](https://github.com/southstar21dev/Droidtosh/security/advisories/new)
for this repository.

Include what you found, how to reproduce it, and which versions are affected. You'll get a reply
within a week; once a fix is released, the advisory is published with credit to you unless you'd
rather stay anonymous.

## Supported versions

Only the latest release, and the latest beta if it is newer, receive security fixes.

## Scope

The Mac app, the Android app, the relay and the protocol between them. How Droidtosh protects your
data is described in [docs/PRIVACY.md](docs/PRIVACY.md), and the wire protocol in
[protocol/PROTOCOL-v2.md](protocol/PROTOCOL-v2.md).
